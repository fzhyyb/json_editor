# JSON 解构 for uTools

一款完全本地运行的 uTools 插件，用于递归展开被转义的 JSON 对象和数组。

## 功能

- 递归展开对象、数组及其中多层字符串化的 JSON 对象和数组。
- 左右对照显示原始 JSON 与 2 空格缩进的处理结果。
- 处理成功后自动复制，并提供“复制结果”按钮再次复制。
- 保留无法解析的嵌套字符串，并以 JSONPath 风格路径显示警告。
- 提示外层解析错误、非对象/数组输入和最大递归深度问题。
- 响应系统深浅主题，窄窗口自动切换为上下布局。
- 零运行时依赖，不联网，不上传、存储或记录输入。

插件采用严格 JSON 语法，不支持 JSON5、JavaScript 对象字面量、注释、单引号或尾逗号。字符串形式的数字、布尔值和 `null` 不会转换为原始类型。

## 使用方法

插件提供两种入口：

1. 在 uTools 中输入“JSON 解构”或“递归解析 JSON”打开插件，把内容粘贴到左侧并点击“解构并复制”。
2. 在任意应用复制 JSON 文本，呼出 uTools，选择“递归解构 JSON”；插件会接收所复制的文本，自动处理并复制结果。

如果某段嵌套字符串看起来像对象或数组却不是有效 JSON，其他字段仍会继续处理，警告区会标出对应路径。自动复制失败时，结果仍会显示，可点击复制按钮或手动复制。

快捷键：

- macOS：`Command+Enter` 执行，`Command+Shift+C` 复制结果。
- Windows/Linux：`Ctrl+Enter` 执行，`Ctrl+Shift+C` 复制结果。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。普通浏览器没有 uTools 剪贴板 API，因此可以预览和处理内容，但自动复制会降级为手动复制提示。

## 运行测试

项目需要 Node.js 18 或更高版本：

```bash
npm test
```

## 接入 uTools

打开 uTools 开发者工具，创建或接入项目时选择项目根目录下的 `plugin.json`。分别验证功能指令入口、复制文本入口、自动处理、复制结果、警告路径、快捷键以及深浅主题。

## 打包 UPXS

在 uTools 开发者工具中确认版本号为 `1.0.0`，仅保留插件运行所需文件，然后按“打包为离线安装包”流程生成 UPXS。安装该离线包，完成目标平台的基本冒烟测试后再提交发布。
