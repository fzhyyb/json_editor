# JSON 编辑器工作台设计

## 目标

将现有左右对照的 JSON 解构工具升级为单编辑器 JSON 工作台。用户从 uTools 文本入口进入或向空编辑器粘贴完整 JSON 后，应用自动递归展开字符串化 JSON 并格式化；用户随后可以直接编辑、搜索、折叠、格式化、压缩、转义、去转义和复制结果。

## 编辑器方案

使用 CodeMirror 6，并在构建阶段将依赖打包到发布目录。运行时不加载 CDN、不发起网络请求，继续保持全部数据只在本机处理。

选择 CodeMirror 6 的原因：

- 原生支持行号、语法高亮、撤销历史、选区和快捷键。
- 官方扩展提供代码折叠、搜索、匹配导航和 JSON 语言支持。
- 相比 Monaco 体积更小，资源与 Worker 配置更简单。
- 相比自研编辑器，光标、输入法、超长文本和搜索行为更可靠。

## 页面结构

采用已确认的“单编辑器工作台”布局：

1. 顶部品牌区：JSON 编辑器、本地处理说明、JSON 有效性状态。
2. 工具栏：递归解析、格式化、压缩、转义、去转义、全部折叠、全部展开、搜索、复制、清空。
3. 主编辑器：行号、折叠槽、语法高亮、当前行提示和浏览器原生输入法支持。
4. 底部状态栏：行列位置、行数、字符/字节大小、缩进和递归深度信息。
5. 临时反馈：自动解析成功、复制成功或操作错误通过非阻塞状态消息呈现。

界面跟随系统深浅主题。窄窗口下工具栏允许换行并收紧文案，不缩小编辑区到不可用宽度。

## 自动处理

- 从 uTools 文本匹配入口进入：若载荷是字符串，立即写入编辑器、递归解析并格式化。
- 编辑器为空或当前内容被全选时粘贴完整 JSON：拦截该次粘贴，递归解析剪贴板文本并将格式化结果写入编辑器。
- 在非全选的已有内容中粘贴：按普通编辑操作插入，只触发实时校验，不自动重排全文。
- 手动编辑：延迟约 200 毫秒进行 JSON 语法校验，不自动格式化或移动光标。
- 点击“递归解析”：对当前完整文档再次执行现有递归解构逻辑。

自动处理生成一次可撤销的编辑事务，用户可以通过 `Command/Ctrl+Z` 恢复粘贴前内容。

## 基础功能语义

### 格式化

解析当前完整文档并以 2 个空格缩进输出，不递归展开字符串化 JSON。兼容现有的非标准单字符转义修复。结构无效时不改变文档并提示错误。

### 压缩

解析当前完整文档并使用无额外空白的 JSON 字符串替换文档，不递归展开字符串化 JSON。无效输入不改变文档。

### 转义与去转义

- 有非空选区时只处理选区；没有选区时处理完整文档。
- 转义：使用 JSON 字符串语义增加一层转义和外层引号。
- 去转义：要求目标是合法 JSON 字符串，解析并移除一层外层字符串编码；结果是对象/数组文本时保留其原始字符串内容，不自动格式化。
- 操作只执行一层，允许用户重复点击处理多层转义。

### 折叠

- 折叠槽支持单独折叠对象和数组节点。
- 工具栏提供全部折叠和全部展开。
- 折叠只改变显示状态，不改变 JSON 文本。

### 搜索

- 使用 CodeMirror 搜索面板，支持匹配高亮、匹配计数、上一个和下一个。
- `Command/Ctrl+F` 打开搜索；`Enter` 和 `Shift+Enter` 在结果间移动；`Escape` 关闭。

### 复制与清空

- 复制始终是显式操作，复制当前完整编辑器文本。
- 清空编辑器、折叠状态、错误状态和操作反馈，并聚焦编辑器。

## 校验与错误

- 实时校验使用严格 JSON 语法；格式化、压缩和递归解析可使用现有严格优先、非法转义兼容回退能力。
- 编辑过程中 JSON 无效时，在状态区展示简短错误，编辑内容不丢失。
- 工具操作失败时不覆盖编辑器或剪贴板。
- 递归解析继续保留 100 层安全深度；输入字符长度不设置应用层上限。

## 模块与构建

- `src/json-unwrapper.js`：保留递归展开；导出格式化/压缩所需的单次兼容解析与序列化能力。
- `src/editor-operations.js`：纯文本操作，包括格式化、压缩、单层转义与去转义，便于独立测试。
- `src/app.js`：创建 CodeMirror 编辑器、注册工具栏动作、处理 uTools 入口、粘贴自动解析和状态更新。
- `styles.css`：工作台、CodeMirror 覆盖样式、主题和响应式布局。
- `scripts/build-app.mjs`：使用 esbuild 将浏览器入口与 CodeMirror 依赖打包为单个运行时脚本。
- `scripts/build-release.mjs`：构建应用后复制运行时 HTML、CSS、bundle、manifest 和 Logo。

## 测试与验收

- 纯操作测试覆盖格式化、压缩、单层转义/去转义、选区替换语义和错误保留。
- 控制器测试覆盖 uTools 入口自动解析、空编辑器完整粘贴自动解析、局部粘贴不重排、显式复制和清空。
- 结构测试覆盖工具栏、单编辑器容器、有效性状态和无 `maxlength`。
- 清单测试继续验证实际不限长度的文本入口。
- 三个用户实际样例经新版正式解析路径展开数量分别为 18、23、2，警告均为 0。
- 格式化输出为 2 空格缩进，压缩输出无多余空白。
- 折叠与搜索能在大 JSON 上工作，编辑过程中保持撤销能力。
- 完整测试、运行时语法检查、发布构建和本地浏览器冒烟通过。
