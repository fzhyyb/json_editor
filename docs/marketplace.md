# uTools 应用市场素材

## 基本信息

- 应用名称：JSON 解构
- 一句话简介：一键递归展开多层转义的 JSON 对象和数组。
- 首版说明：支持复制文本直接唤起、左右对照、自动复制、嵌套错误路径提示以及深浅主题。

## 截图清单

- 处理前后的左右对照界面。
- 复制文本后自动处理并显示成功状态。
- 含嵌套错误路径的警告界面。
