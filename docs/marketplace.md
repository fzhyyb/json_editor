# uTools 应用市场素材

## 基本信息

- 应用名称：JSON 编辑器
- 一句话简介：自动解析、格式化并编辑多层转义 JSON。
- 首版说明：升级为单编辑器工作台，支持粘贴自动解析、格式化、压缩、转义/去转义、折叠、搜索、实时校验和深浅主题。

## 应用介绍与用户手册

JSON 编辑器用于编辑、格式化并递归展开多层转义的 JSON 对象和数组。你可以在 uTools 中输入“JSON 编辑器”“JSON 格式化”或“JSON 解构”打开工作台；也可以先复制 JSON，呼出 uTools 并选择“使用 JSON 编辑器打开”。从文本入口进入或向空编辑器粘贴完整 JSON 时，插件会自动递归展开并格式化。

工作台提供行号、语法高亮、实时校验、节点折叠、全文搜索、格式化、压缩以及选区优先的单层转义/去转义。只有点击“复制”或使用复制快捷键才会写入剪贴板。插件优先使用严格 JSON，并兼容字符串内部的非标准单字符转义（如 `\&`）；不支持 JSON5、注释、单引号、尾逗号或 JavaScript 对象字面量。输入字符长度不设实际限制，递归深度保留 100 层安全上限。

macOS 使用 `Command+Enter` 执行、`Command+Shift+C` 复制结果；Windows/Linux 使用 `Ctrl+Enter` 执行、`Ctrl+Shift+C` 复制结果。所有处理均在设备本地完成，不联网，不上传、存储、记录或分享输入；详见 [`docs/privacy.md`](privacy.md)。
